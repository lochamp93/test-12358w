ALERTES VARIABLES : DOSSIER DES SONS ET DES VISUELS
===================================================

Ce dossier reste sur VOTRE ordinateur. Streamer.bot lit les fichiers et les
envoie à l'overlay : rien n'est hébergé sur le site du widget.


1. ORGANISATION
---------------

alertes-variables/          Dossier source (à choisir dans le dock)
├── defaut/                 Scénario par défaut (obligatoire)
├── _modele-scenario/       Modèle vide à copier pour un nouveau scénario
└── (vos scénarios)         Ex. : horreur/, chill/ …

- Dans le dock, choisissez le dossier « alertes-variables » lui-même
  (celui qui contient « defaut »), pas un des sous-dossiers.
- Si le bouton « Choisir le dossier » ne fait rien, collez le chemin du dossier
  dans le champ du dock puis cliquez sur « Définir ».
- Un scénario = un sous-dossier. Son nom doit être EXACTEMENT celui du scénario
  dans la page de paramétrage.
- Nouveau scénario : copiez « _modele-scenario », renommez la copie
  (ex. « horreur »), déposez-y vos fichiers, puis cliquez sur « Actualiser ».
- Noms conseillés : minuscules, sans espaces ni accents.


2. NOM DES FICHIERS
-------------------

Un type d'alerte = un nom de fichier. Le son et le visuel portent le MÊME nom,
seule l'extension change :  cheer.gif  +  cheer.mp3

    follow        Follow
    sub           Abonnement
    resub         Réabonnement (sans fichier resub : celui de « sub »)
    gift          Abonnement(s) offert(s)
    cheer         Bits / dons (« bits » fonctionne aussi)
    raid          Raid
    alerte        Fichier de secours pour tous les types (optionnel)

Les noms comme « Twitch_sub_1.gif » ou « Twitch_Raid.gif » ne sont PAS
reconnus : renommez-les (ex. Twitch_Raid.gif → raid.gif).


3. RÈGLES (anniversaires, paliers, montants)
--------------------------------------------

Dans la page de paramétrage, sous chaque alerte qui le permet, « Ajouter une
règle » (jusqu'à 5 par alerte). L'engrenage de la règle affiche le nom exact à
donner au fichier, avec un bouton pour le copier.

  Abonnement (Twitch)
    Prime Gaming / Palier 1, 2, 3   → sub-prime, sub-tier1, sub-tier2, sub-tier3
  Réabonnement
    Tous les N mois                 → sub-tous-les-Nmois   ex. sub-tous-les-12mois.gif
    Exactement N mois               → sub-Nmois            ex. sub-9mois.gif
    À partir de N mois              → sub-Nmois-plus       ex. sub-24mois-plus.gif
  Abonnements offerts
    À partir de N / exactement N    → gift-N-plus / gift-N     ex. gift-10-plus.gif
  Bits, Super Chat, cadeaux TikTok
    À partir de N / exactement N    → cheer-N-plus / cheer-N   ex. cheer-1000-plus.gif
  Raid
    À partir de N / exactement N    → raid-N-plus / raid-N     ex. raid-50-plus.gif

Priorité : « exactement » (et le type d'abonnement), puis « tous les », puis
« à partir de » ; à égalité, le N le plus grand. Sans fichier de règle,
l'alerte habituelle est jouée.


4. FORMATS ACCEPTÉS
-------------------

Sons    : .mp3 (recommandé), .ogg, .wav, .m4a
Visuels : .webm (recommandé : vidéo avec transparence), .mp4, .gif, .webp,
          .apng, .png, .jpg, .svg
Taille maximale : 25 Mo par fichier.
Un seul son et un seul visuel par nom (pas de « sub.mp3 » ET « sub.wav »).


5. FICHIER MANQUANT = FICHIER PAR DÉFAUT
----------------------------------------

Un scénario n'a besoin que des fichiers qu'il change : si un fichier manque,
le widget prend celui du dossier « defaut ». Exemple : « horreur » ne contient
que des sons → les visuels restent ceux du scénario par défaut.

Le dossier « defaut » doit donc contenir un son et un visuel pour chaque type
d'alerte utilisé.
